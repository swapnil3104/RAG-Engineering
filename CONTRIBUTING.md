# Contributing to RAG Learning Journey

Thank you for your interest in contributing! This repository is designed to be an open, structured guide for engineers learning and implementing Retrieval-Augmented Generation.

## How to Contribute
1. **Fork the Repository**: Create your own feature branch (`git checkout -b feature/topic-name`).
2. **Follow Markdown Conventions**: Use clean GitHub Flavored Markdown with clear code snippets and mermaid diagrams.
3. **Code Quality**: Ensure any Python scripts or notebooks follow PEP 8 standards.
4. **Submit a Pull Request**: Provide a descriptive summary of your changes.

## Code of Conduct
Please maintain a respectful, constructive, and inclusive community environment.
